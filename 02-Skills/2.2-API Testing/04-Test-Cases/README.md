# API Test Cases

## Overview

This section contains the test cases designed for the **Customer REST API** developed in Business Central.

The test cases are designed to verify API functionality, data validation, and expected system behavior.

## Test Coverage

The test cases cover:

* GET — Retrieve customer data
* POST — Create customer
* PATCH — Update customer
* DELETE — Delete customer
* Positive testing
* Negative testing
* Boundary testing
* Data type validation
* Required field validation
* Duplicate data validation

## Test Case Structure

Each test case contains:

* Test Case ID
* Test Objective
* Preconditions
* HTTP Method
* Endpoint
* Test Data
* Expected Result
